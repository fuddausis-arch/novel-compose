# React + Electron 客户端前端重写设计

## 目标
把当前原生 HTML/JS 前端重写成 macOS 风格的桌面客户端，解决复制粘贴失效、生成结果不可见、格式混乱等体验问题。

## 技术栈
- Electron 30 + Vite
- React 18 + TypeScript
- Tailwind CSS
- shadcn/ui 组件库
- react-query（数据获取与缓存）
- zustand（轻量状态管理）

## 视觉风格
- macOS 液体玻璃（Liquid Glass）：半透明磨砂背景、动态模糊、柔和边框、圆角卡片
- 深色主界面 + 亮色内容区
- 窗口无边框或细边框，顶部自定义标题栏

## 窗口布局
```
┌─────────────────────────────────────────────────────────────┐
│ [≡]  小说生成器                              [_][□][×]      │ 标题栏（液体玻璃）
├──────────┬──────────────────────────────┬───────────────────┤
│ 项目选择 │                              │                   │
│ ─────────┤     工作区                    │   AI 流水线面板   │
│ 资产树   │   - 项目概览                  │   - 节点状态      │
│ 角色     │   - 章节编辑器                │   - 事件日志      │
│ 伏笔     │   - 文档导入                  │   - 生成按钮      │
│ 大纲     │   - 导出                      │                   │
│ 章节     │                              │                   │
└──────────┴──────────────────────────────┴───────────────────┘
```

## 功能模块
1. **项目管理**：新建/选择/删除/编辑项目
2. **资产树**：角色、伏笔、大纲、章节的 CRUD
3. **章节编辑器**：大文本区编辑 + 保存，自动清理 markdown 格式
4. **AI 流水线面板**：生成进度、节点状态、错误提示
5. **文档导入**：文本域粘贴任意文档，AI 解析导入设定
6. **导出**：下载 TXT

## 后端接口
完全复用现有 FastAPI，无需修改：
- `/api/projects`
- `/api/bible/{project_id}/...`
- `/api/chapters/...`
- `/api/planning/...`

## 启动方式
开发：`npm run dev`（启动后端 + Vite + Electron）
打包：`npm run build:electron`

## 关键改进
- 文本域使用 shadcn/ui 标准组件，复制粘贴正常
- 生成完成后自动打开对应章节
- 全局 Toast 错误提示
- 加载状态明确
- 类型安全减少运行时错误
