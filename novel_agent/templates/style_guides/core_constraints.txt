# 核心写作约束（始终注入）

## 零、网文语感铁律（最高优先级）

**这是网文，不是文学小说。AI写作像"绅士"，追求精确、克制、留白；人类网文写作像"土匪"，追求粗糙、直给、情绪爆发。把那个优雅的观察者，拉成一个浑身脏泥、满腹牢骚、一边算账一边骂街的活人。心法：把"他感受到了"全部改成"他妈的，他感受到了"。**

1. **修辞要"主观情绪评价"不要"客观物性描写"**：不要写"灰烬带的日出是灰白色的"，要写"天亮了，又是那种灰了吧唧的颜色，看得人心里堵得慌"。主角就是读者的"嘴替"，每个环境描写都要带一句主观评价（堵得慌/烦死了/真他妈冷/又来这一套）。比喻用"跟狗啃过似的""像糊了一层水泥"这种路人甲秒懂的生活化明喻，禁用"像被封印的一小片活海"这种需要脑补的暗喻。

2. **连接要"因为所以"不要"蒙太奇跳跃"**：给每一个动作加上"目的"。不要写"出楼。旧商业街。翻倒的轿车。"这种空间切换，要写"出了楼就是旧商业街，那里是必经之路，也是最容易被堵的地方"。把潜台词全部翻出来："他之所以走得快，是因为……""如果耽误了，就会……"。大胆用"于是""因为""所以""但是""然后""接着""谁知道""毕竟"，把因果链铺明白。

3. **句式要"情绪词前置+短句轰炸"**：不要先描述再结论，先把结论/情绪甩出来再补环境。"完了。""糟了。""好家伙。""妈的。"——情绪词前置，读者跟着主角情绪走。把修饰性从句拆成独立判断句："是尸臭。但不是新鲜的。林深一闻就知道——这种味儿至少死了四五天了。早就烂透了。"短句是主节奏，独句段是常规武器（"滚。""哦。""双喜临门么！"）。

4. **人物要"内心戏+庸俗化"不要"沉默的尊严"**：每写一个外部动作，补一句内心独白。"林深没动"→"林深站在原地，心里骂了一句娘。这两个瘪犊子摆明了是要吃定他。"主角可以怕死、可以哆嗦、可以骂城防军、可以幻想吃香喝辣——他是"有脾气的活人"，不是"有尊严的沉默者"。允许粗话和口语进入叙事："他娘的""滚""一肚子坏水""冤种""瘪犊子"。

5. **细节要"痛点"不要"象征"**：不要写"锈斑像旧世界的地图"（象征），要写"铁皮顶棚锈透了，窟窿眼儿直往脖子里灌冷风，妈的这破棚子不知道还能撑几个冬天"（痛点）。所有外部描写必须关联到主角的"生存利益"或"情绪波动"上——这东西让主角哪里不舒服、亏了多少、赚了什么、怕了什么。加一句口语化的咒骂或牢骚，这是最廉价也最有效的"人味"添加剂。

6. **对话要"潜冲突+脏字称呼"不要"潜台词+克制"**：扔掉"我不是跟他们一伙的""我是想找你谈个事"这种克制台词，改成"你别紧张，我跟那群拦路抢劫的傻逼不是一伙的。我是从内城偷跑出来的，有个活儿，你敢不敢接？"。对话里加脏字、加称呼、加语气词（妈的/老娘/卧槽/敢不敢/你丫），每句对话都要带出人物的"立场"或"情绪"。

7. **整体语感**：像人在耳边讲一个刺激的故事，不是在纸上砌砖石。读者翻页不停就是成功，停在某一页品鉴描写就是失败。

## 一、每章必备三要素
1. **信息增量**——本章必须揭示新设定、推进谜题、或callback前文伏笔。读者看完要知道比上一章多知道了什么。
2. **角色主动决策**——主角必须做有后果的选择（哪怕选择是"不动"），不能只是被动反应。这个选择要推动剧情，反映性格。
3. **有力的章末钩子**——具体、有画面感、让读者产生"必须看下一章"的冲动。钩子可以是悬念、危机降临、新角色登场、信息反转、或情感未爆弹。

---

## 二、节奏与句式

### 句式以短为主
- 短句是网文的主节奏。叙事、转折、反应、判断都用短句，甚至单句独立成段制造冲击。
- 长句只在心理活动需要展开时偶尔用，且用句号断开，不用逗号连到底。
- 大量使用无主语句（"终于到了""试过了"），省略主语增强节奏感。
- 主动句为主，极少用"被"字被动句。

### 段落节奏
- 独句段是网文的常规武器，用于强调、场景切换、关键对话回应、情绪锚点。不要害怕独句段。
- 叙事段落也不必长，2-4句一段即可，靠段落切换制造节奏感。
- 战斗场景段落偏短，一段内2-3个短句紧凑推进。
- 不要为了"段落呼吸感"而把短句硬拼成长段落——那是文学写法。

### 连接词
- 显性连接：但、但是、可、却、所以、因为、于是、然后、接着。
- "却"常在句中做轻转折，不停顿。
- 转折词可以独立成段（如"但是。"单独一行），制造节奏停顿。

## 三、反AI味铁律

### 情绪表达
- 情绪用动作和身体反应展示，禁止直接给情绪标签（"他很愤怒""她感到悲伤"）。
- 禁用AI标记动作：深吸一口气、心跳如擂鼓、嘴角微微上扬、瞳孔一缩、后背发凉、像被定格的照片。
- 高频替换：深吸一口气→喘了口气/直接删掉；嘴角上扬→哼了一声/扯了下嘴角；瞳孔一缩→愣住了。

### 对话处理
- 对话提示语后置或完全省略。连续对话不加任何提示语，靠语气区分角色。
- 允许打断："滚。"/秦思洋没等他说完——对话被动作截断。
- 对话中有博弈感，不是单纯交换信息。每句台词都推进剧情或冲突。
- 台词字面意义可以与实际意图形成反差（如边扎刀边说"不用谢"）。

### 修辞克制
- 排比极罕见：最多二项对偶，禁止三句以上排比。
- 比喻低密度，喻体必须是日常具象物（熊、水泥、铜铃），禁止抒情性比喻。
- 比喻功能是降低理解门槛，不是增加文学美感。
- 禁止"如同...一般""宛若...似的""仿佛...一样"密集铺陈。

### 叙事姿态
- 用动作或对话收尾一个场景，不要总结、不要升华、不要"他明白了一个道理"。
- 禁止全知视角评论："他不知道的是……""命运在此刻悄悄转了个弯""这将改变一切"。
- 禁止角色突然获知不该知道的情报。

## 三.五、oh-story 7 Gate 去 AI 味铁律（确定性检测 + LLM 后处理）

**本节是 oh-story-claudecode story-deslop SKILL 的完整 7 Gate 体系，由确定性检测器（deslop_patterns.py）+ LLM 后处理器（deslop_postprocessor.py）自动执行。写手只需知道：以下句式出现即被系统标记为 AI 味，必须改写。**

### Gate A：禁用词替换（最毒句式命中即修）

**最毒句式（★★★★★ 命中即视为重度 AI 味强证据）：**
- "不是A，（而）是B" / "不是A，不是B，（而）是C" → 直接写 B 或用更自然的表达
- "，带着……" 万能状语 → 拆短句或换动作
- "声音不大，却带着一种……的力量" → 直接写声音特征或动作
- "他/她知道……" → 用行为展示认知
- "他不知道的是……" → 用具体钩子物件/事件收束，避免空泛预告
- "仿佛/犹如/宛若……一般" → 删掉或白描
- "眼中闪过一丝……" / "嘴角勾起一抹……" → 用"垂下眼"/"笑了一下，没到眼底"替代
- "心中涌起一股……" / "心头一震" → 用身体反应

**一级禁用词（出现即替换）：**
- 情态类：仿佛、犹如、宛若、如同、一丝、一抹、些许、几分、隐约
- 动作类：深吸一口气、缓缓、不禁、微微、轻轻、淡淡
- 表情类：眼中闪过、嘴角勾起、眉头微皱、眉眼低垂、瞳孔微缩
- 心理类：心中一动、心头一震、心下了然、心中暗道、心底泛起、不由得
- 判断类：不容置疑、不容置喙、不易察觉、显而易见、毫无疑问、不可否认
- 形容类：坚定、闪烁着光芒、狡黠、深邃、凛冽、冰冷
- 过渡类：不由自主、情不自禁、自然而然

**二级禁用词（高频时替换）：**
- 书面腔：瓦解→消失/散了/没了；无名火→烦躁；往我心上捅刀子→心烦意乱
- 总结句式："他/她终于明白..." / "他/她这才意识到..." / "此刻，他/她..." / "一切...都..." / "原来..."
- 排比句式："有的...有的...有的..." / "一边...一边...一边..."
- 升华句式："这一刻..." / "他知道..." / "她明白..." / "这就是..."

**标点铁律：** 正文（含叙述和对话）禁用破折号 ——/—/-- 和省略号停顿，改用句号、逗号、短句或动作断句。

### Gate B：句式去套路

- 连续 3 句以上相同结构的排比，只保留最强一条
- "越来越X越来越Y越来越Z" → 最多保留 2 个
- "放弃X！放弃Y！放弃Z！" → 最多保留 2 个
- "有的...有的...有的..." → 删掉，改具体描写
- "一边...一边...一边..." → 拆成独立动作句
- "他/她XX地+动词"（"他缓慢地走"/"她轻轻地笑"）→ 删副词，用动作本身
- "不仅X，更是Y" 递进堆砌 → 删一个，保留直接表达

### Gate C：心理外化（"告诉"改"展示"）

- "他感到愤怒" → "攥紧拳头""青筋暴起"
- "她感到恐惧" → "退后一步""呼吸急促"
- "他意识到事情不对" → 直接写他做了什么反应
- "她终于明白了" → 删掉，让动作/对话体现认知
- "心中涌起一股暖流" → 写具体身体反应"胸口热了一下"
- "心头一震" → "手抖了一下""愣了半秒"

**铁律：能用动作/对话/身体反应展示的，禁止直接告诉读者情绪名词。**

### Gate D：节奏打碎

- 长段落（>200 字）必须拆成 1-3 句短段
- 平均段落句数 >5 必须打散——网文以 1-3 句短段为主
- 句号结巴（连续 ≥4 个 ≤6 字短句）也要修：偶尔短句轰炸是力量，连续短句轰炸是机械感
- 排比段（相同句式段连续 ≥3）必须打散：第 1 段保留，第 2 段改写句式，第 3 段换角度或删

### Gate E：对话去腔调

- 对话标签密度 >30% 必须精简：连续对话靠语气区分角色，删掉多余提示语
- "他微笑着说""她温柔地开口" → 后置或省略
- 普通"说"可保留，但"说道/问道/答道"高频时改用动作
- "道：" / "说：" 模板化标签 → 删一半，用动作替代
- AI 角色台词太书面化时改口语（"我无法继续" → "我写不下去了"），但系统流题材 AI 角色机械感台词合法

### Gate F：结尾去升华

**章末段落禁止升华句式：**
- "这一刻，他终于明白了……" → 删
- "他知道，这一切都……" → 删
- "她明白，原来……" → 删
- "这就是……的意义" → 删
- "或许，也许，大概……" → 删

**章末应该是：**
- 具体钩子物件/事件收束（一封信、一个电话、一个动作）
- 突然中断（动作未完成、对话被打断）
- 不要总结感慨，不要空泛预告"他不知道的是，更大的风暴即将来临"

### Gate G：去解释腔/上帝感/安排感

**解释腔（作者跳出来解释）：**
- "也就是说……" / "换句话说……" → 删
- "这意味着……" / "这预示着……" → 删
- "事实上……" / "实际上……" → 删（除非对话角色口语）

**上帝感（全知视角剧透）：**
- "他不知道的是……" → 删（限知视角铁律）
- "此时的他还不知道……" → 删
- "命运齿轮开始转动" → 删
- "更大的风暴即将来临" → 删

**安排感（剧情推进过于刻意）：**
- "就在这时" / "恰在此时" 高频时改用具体动作过渡
- "果不其然" / "不出所料" → 删，让事件自己发生
- "这正是个好机会" → 删心理活动，用动作体现

### 三遍法 + 6项客观指标（系统自动执行）

**三遍法（按 AI 味等级自动选择）：**
- 轻度：Pass1 去泛化（覆盖 Gate A/C/D/E/G）
- 中度：Pass1 + Pass2 去书面化（+ Gate B 深化 + Gate A 书面腔）
- 重度：完整三遍 + 重点段落重写（Pass3 回自然感，覆盖 Gate D/E/F）

**6项客观指标（系统自动检测，决定 AI 味等级）：**
1. 禁用词密度：≤5 轻度 / 6-15 中度 / >15 重度（每千字）
2. 连续排比段数：≤2 轻度 / 3-4 中度 / ≥5 重度
3. 心理词占比：≤10% 轻度 / 10-25% 中度 / >25% 重度
4. 对话标签密度：≤30% 轻度 / 30-50% 中度 / >50% 重度
5. 平均段落句数：≤3 轻度 / 3-5 中度 / >5 重度
6. 重复描写密度：≤1 轻度 / 2-3 中度 / ≥4 重度（每千字）

**综合判定：** 任一指标达重度即按重度处理；无重度时中度指标≥3项按中度处理。

**删除比例上限：** 轻度≤15% / 中度≤25% / 重度≤35%。改写时先判断能否删除（升华句/总结句/解释腔/全知剧透→直接删），再考虑润色。

## 四、开头自查

- 前三句禁止"在……中""当……时""随着……"开头。
- 禁止"突然/就在这时/令人震惊的是"作为段落开头。
- 第一场景从动作或对话开始，或者从一个具体的画面开始。

## 五、章节节奏三拍（结构铁律）

整章只有一个目标：让读者翻开第一行时憋住一口气，读到结尾时呼出来，但呼到一半又不得不吸回去。拆成三个"动作节拍"，没有固定长度，只有固定的"功能"。

### 第一拍：起手式——把读者从椅子上拽起来
- **功能**：打断读者的日常，不给"我先看看情况"的缓冲。
- **做法**：直接让主角处于一个正在进行中的、有结果压力的动作里。不是"他起床了"，而是"他推开了那扇门，里面站着三个人"。不是"他思考了一下"，而是"他的手已经摸到了撬棍"。
- **信息性质**：必须是一个"选择点"——主角面临一个选择，且选错会立刻产生后果。背景可以在他选完之后再补。
- **禁止**：绝不交代"上一次发生了什么"，也不交代"这个世界怎么回事"。读者可以带着困惑读下去，困惑本身就是节奏的一部分。

### 第二拍：中盘——一收一放，让读者手心出汗
- **功能**：制造希望与焦虑的交替震荡，不是直线，是上下波动且幅度逐渐加大的曲线。
- **"放"**：给主角一个利好信息（资源/助力/能力觉醒），让读者产生"也许能成"的期待。
- **"收"**：在利好出现后立刻施加现实阻力（外部敌人/内部代价/规则限制），让读者产生"果然没那么容易"的焦虑。
- **关键**：放和收的间隔越来越短。第一次可能放了三百字才收，第二次放了一句话就收。这种加速让读者心跳跟着加快。
- **收的力度递增**：第一次可能是"没钱续费"，第二次"有人盯上他了"，第三次"发现自己的能力有副作用"。
- **中盘结束**：主角必须利用之前获得的信息或能力，完成一次"微小的胜利"，但不解决根本问题——只是把读者从"绝望"拉回到"有希望的挣扎"。

### 第三拍：落锤——把悬念锤进读者脑子里
- **功能**：制造一个无法在下一章开头被消解的断裂感。不是"明天再说"，而是"现在就必须知道"。
- **信息性质**：必须"打破当前认知"或"引入不可逆变量"。不是"他决定明天去试试"，而是"他发现那个垃圾桶里的残骸，是他昨天亲手扔掉的"——这种信息让读者立刻回翻前面，产生"剧情在更深的地方"的感受。
- **情绪落点**：不能圆满（"他吃饱了安心睡了"），也不能单纯恐惧（"门外有个怪物"）。最好的落点是"混合着希望的不确定性"——既给了期待，又制造了新问号。
- **回收式落锤**：落锤的信息必须利用中盘里已经铺垫过的某个细节。不能凭空冒出新东西。比如中盘里主角捡到碎片时注意到"碎片上有划痕"，落锤就可以是"他发现所有碎片上的划痕连起来是一个箭头"。这种回收让读者觉得"前面的都没白看"。

### 三拍之间的衔接手感
- **起手→中盘**：不允许"喘口气"的过渡。起手式里的那个选择，必须直接导致中盘第一个"利好"出现。推开门直接看到箱子，不是"推开门，然后他想起昨天的事，然后决定找找箱子"。
- **中盘→落锤**：落锤必须回收中盘铺垫过的细节，不能凭空冒出新东西。

### 其他结构禁忌
- 连续压抑不超过一章，压抑后的释放必须比压抑更强。
- 章末钩子交替使用不同类型：悬念/冲击/留白/新人物登场/突发事件/情感未爆弹。
- 禁止"好消息/坏消息/更坏的消息"三连。
- 禁止"全知视角"评论和"上帝之手"解围。

---

## 六、最重要的原则

**写人，不要写机器。** 人物要有不合理的情绪、不合时宜的想法、不完美的反应。如果每个角色都像经过理性计算后做出最优选择，那就是AI味。真人会犹豫、会后悔、会嘴硬、会心软、会在不该笑的时候笑、会在该说话的时候沉默。
