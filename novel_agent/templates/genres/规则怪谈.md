# 规则怪谈

## 核心卖点
诡异规则下的生存博弈，解读规则、利用规则、探寻规则背后的真相。

## 推荐约束包
- 规则必须有内在逻辑，不能自相矛盾无解释。
- 恐怖氛围来自未知和限制，而非血腥。
- 主角的存活必须基于推理，不能纯靠运气。

## 世界观与规则
| 类型 | 说明 | 示例 |
|---|---|---|
| 场景规则 | 特定地点的规则 | 医院、学校、列车 |
| 身份规则 | 扮演特定身份需遵守的规则 | 员工、学生、乘客 |
| 时间规则 | 特定时间触发的规则 | 午夜、雨天 |
| 对抗规则 | 与诡异存在互动的规则 | 不能回头、不能答应 |

## 经典爽点套路
1. **规则解读**：从矛盾规则中找出生路。
2. **反杀诡异**：利用规则反制规则制定者。
3. **真相揭露**：规则背后是人还是更高存在。
